# 💼 Portfólio - Lucas Bitencourt

Portfólio pessoal desenvolvido com React + Vite, apresentando minhas habilidades, projetos e informações de contato.

## 🚀 Tecnologias

- React
- Vite
- CSS3
- JavaScript

## 🎨 Características

- Design minimalista com tema escuro
- Layout responsivo
- Seção de skills com ícones das tecnologias
- Links para projetos no GitHub
- Botões de contato para LinkedIn, GitHub e Instagram

## 📦 Instalação

```bash
# Clone o repositório
git clone https://github.com/Lkzin0122/portfolio.git

# Entre no diretório
cd portfolio

# Instale as dependências
npm install

# Execute o projeto
npm run dev
```
